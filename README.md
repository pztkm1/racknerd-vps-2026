**选哪个数据中心对国内访问速度最好？**

**VPS 开通之后怎么连上去？**

付款完成后你会收到邮件，里面有服务器 IP 地址、root 密码和 SSH 端口（默认 22）。用任何 SSH 客户端连接即可，比如 Windows 上用 PuTTY 或者系统自带的终端，Mac/Linux 直接 `ssh root@你的IP` 就行。
